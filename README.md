# 🚀 ISRO Mission Data Analysis Dashboard

# 📊 Overview

This project presents an interactive dashboard analyzing space missions inspired by publicly available data sources such as ISRO mission reports.

# 🛠 Tools Used

* Microsoft Power BI
* Power Query
* DAX
* Microsoft Excel

# 📈 Features

* KPI cards (Total Missions, Success Rate)
* Mission trend analysis (Year-wise)
* Rocket performance comparison
* Interactive filters (Year, Rocket, Status)

# 📂 Files

* ISRO_Missions.pbix
* Dataset.xlsx
* Dashboard Screenshot.png

# 📌 Key Insights

* High mission success rate
* PSLV is the most used launch vehicle
* Increasing trend in recent missions

# ⚠️ Note

This dataset is curated for analysis purposes using publicly available information.
